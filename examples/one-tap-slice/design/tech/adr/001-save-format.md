# ADR-001: формат сохранения рекорда

## Context
Сохраняется одно число; spark#E3 требует, чтобы ошибка записи не ломала забег.

## Options
| Вариант | Плюсы | Минусы | Стоимость |
|---|---|---|---|
| PlayerPrefs | одна строка кода | нет версии, неудобно тестировать | 0.1 дня |
| JSON в persistentDataPath за интерфейсом | версия, тестируемость через подмену | чуть больше кода | 0.5 дня |

## Decision
JSON за `IRecordStorage` с полем `version`.

## Consequences
EditMode-тест spark#E3 возможен без файловой системы.

## Revisit when
Появится облачное сохранение.
