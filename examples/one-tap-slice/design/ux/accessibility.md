# Accessibility — Lantern Hop

| # | Пункт | Статус (pass / gap / n/a) | Решение |
|---|---|---|---|
| A1 | Громкость по шинам | pass | Music / SFX в настройках |
| A2 | Субтитры с именем говорящего, размер настраивается | n/a | речи нет |
| A3 | Информация не только цветом | pass | фонарь — круг, искра — ромб; check_palette PASS |
| A4 | Информация не только звуком | pass | у каждого звука визуальный дубль (FB) |
| A5 | Размер текста и масштаб UI | gap | в слайсе нет настройки масштаба — decisions-log: отложено до MVP |
| A6 | Hold → toggle | gap | удержание — ядро механики (P1); альтернатива: режим «тап-старт / тап-стоп» заряда — ГИПОТЕЗА, проверить в плейтесте MVP |
| A7 | Пауза в любой момент | pass | сворачивание = пауза (hop#E4) |
| A8 | Переназначение управления / размер тач-целей | pass | весь экран — тач-цель; «ещё» 48 dp |
| A9 | Без вспышек 3+ в секунду, опция снизить тряску | pass | вспышка искры 1 раз, тряски нет |
| A10 | Регулировка сложности или помощи | gap | допуск hop#K4 — кандидат в опцию помощи, решение после плейтеста |
| A11 | Повтор туториала и подсказок | n/a | туториала нет, обучение действием |
| A12 | Однорукая игра (мобайл) | pass | портрет, один палец |
