# import/

**Статус:** `gamedesigner` → встроен как `plugins/gd/skills/syncario-gamedesigner` (v0.2.0).

Сюда кладутся твои собственные скиллы для интеграции в плагин `gd`.

## Как положить
- Скилл из claude.ai: Настройки → Возможности → Скиллы → скачать → распаковать сюда как `import/<skill-name>/SKILL.md` (+ его файлы).
- Любой другой скилл — папкой с `SKILL.md`.

## Что происходит при интеграции (попроси Claude Code: «встрой скиллы из import/»)
1. **Проектные скиллы** (например, `gamedesigner` для Syncario) остаются отдельными: копируются в `plugins/gd/skills/<project>-<name>/` без изменения смысла. Меняется только `name` (если нужен префикс проекта) — по согласованию.
2. **Общие принципы** из них (методология, тон, форматы) выносятся в `plugins/gd/skills/gd-router/references/principles.md` → раздел «Принципы из проектных скиллов», с пометкой источника.
3. Если общий принцип противоречит правилам плагина — Claude показывает конфликт и ждёт решения. Ничего не удаляется и не переписывается по смыслу без согласования.
4. Описание (`description`) проектного скилла проверяется на пересечение триггеров с общими скиллами; правки триггеров — только с подтверждения.
5. Оригиналы остаются в `import/` как источник истины.
