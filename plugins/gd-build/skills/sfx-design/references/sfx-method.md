# SFX: метод, рецепты, источники, громкость

Источники: unity-kit `unity-audio` (MIT, в ATTRIBUTION) — честность проверки («звучание не проверялось»); CCGS `team-audio`, агент `sound-designer` (MIT) — слои и роли; sirruf/music-gen-skill (MIT) — прямая обработка sox/ffmpeg. Код не копировался; `loudness.py` — своя реализация BS.1770 (коэффициенты K-фильтра по формулам libebur128 / pyloudnorm, MIT).

## 1. От события к рецепту
Строка `event-map.md` (событие, Source `<system>#FB*`, Type, Variations) + Feedback GDD (что видит игрок в тот же кадр) + `audio-bible.md` (sonic identity, запреты, SFX rules, Loudness). Звук описывается тремя слоями:
| Слой | Роль | Типично |
|---|---|---|
| Транзиент | «когда» — совпадает с кадром импакта | шум 10–60 мс, highpass, быстрый decay |
| Тело | «что» — материал, высота, вес | тон/свип 80–400 мс; тяжёлое — ниже и длиннее |
| Хвост | «где» — пространство, затухание | фильтрованный шум / ревёрб sox |
Запреты sonic identity (например «без 8-бит») — жёсткие: square/saw как тело для такой игры не годятся.

## 2. Рецепт `design/audio/sfx-recipes.json` (игры)
Формат — docstring `scripts/synth_sfx.py`, пример — `references/recipes-example.json`. Имя рецепта = хвост события в нижнем регистре (`event:/SFX/Player/Land` → `land`). Вариации: `vary.cents` (высота), `vary.gain_db`, `vary.start_ms` (сдвиг слоёв) — число файлов = Variations из карты. `--seed` пишется в `files.md` (колонка Author: `synth_sfx.py seed 7`) — повтор даёт тот же файл побайтно.

## 3. Обработка (если нужна) — sox / ffmpeg
- Ревёрб хвоста: `sox in.wav out.wav reverb 40 50 60` (затем обрезка тишины `silence -l 1 0.1 0.1% reverse silence 1 0.1 0.1% reverse`).
- Частота и битность под библию: `sox in.wav -r 48000 -b 16 out.wav` (передискретизация высокого качества — `rate -v`).
- Нормализация по громкости (двухпроходная EBU R128): `ffmpeg -i in.wav -af loudnorm=I=-20:TP=-1.5:LRA=7:print_format=summary -ar 48000 out.wav`.
- Проверка пика: `ffmpeg -i f.wav -af ebur128=peak=true -f null -` (секция True peak).

## 4. Внешние CC0-источники
Только CC0 или собственная запись: Kenney (kenney.nl, CC0), Freesound с фильтром лицензии CC0 (у каждого звука своя лицензия — проверяй страницу), OpenGameArt с фильтром CC0. В `files.md`: Source `cc0`, License `CC0`, URL страницы звука, Author. CC-BY — только по решению человека (нужны титры), NC и «royalty free без лицензии» — не берём. Нейросетевые генераторы (в том числе с некоммерческими весами) не используем.

## 5. Громкость (AF4)
Цель — Integrated из таблицы Loudness библии (для микса). Отдельный SFX может отличаться: допуск `--lufs-tol` (по умолчанию ±6 LU); иерархию микса выставляют шины FMOD, а не файлы. Короткий файл (< 400 мс) меряется одним блоком без стробирования — число для сравнения SFX между собой, не для отчёта о мастере. Пик — true peak через ffmpeg; без ffmpeg — sample peak с пометкой.

## 6. Манифест и статусы
Строка `files.md` на каждый файл (формат — `check_audio_files.py`). Статусы: `ph` (плейсхолдер, префикс `ph_`) → `todo` → `final` (ставит человек после прослушивания). Скилл пишет «звучание не проверялось» — слушает человек на целевом устройстве.
