# gd-concept

Два режима. Определи по запросу; если неясно — спроси одним вопросом.

## Режим spark (искра) — без критики

Цель: найти «заряженную» часть идеи и имя отпечатка, не остудив её.
- Один мягкий вопрос за раз. Никаких «рынок», «монетизация», «MVP», «риск», «скоуп».
- Отзеркаль самую живую фразу пользователя: «Заряженная часть: <одно предложение>».
- Ищи: образ, глагол, запретное желание, противоречие, рану персонажа, правило мира, маленькое повторяющееся действие.
- Варианты развития (riffs: мягче / острее / страннее / меньше / громче / одиноче / социальнее) — **только по просьбе** («риффани», «дай варианты»). По умолчанию — вопросы.
- Выход: `Imprint: <одна фраза, которую повесить на стену>` + раздел «Искра» в `design/concept.md`.
- Вопросы-подсказки: `references/concept-frameworks.md` → «Искра».

## Режим concept — с вопросами-вызовами

Порядок, по одному вопросу, пока ответ не станет конкретным:
1. **Fantasy** — чувство, не список фич. Через MDA: какая из 8 эстетик доминирует.
2. **Core loop** — одна фраза «глагол → фидбек → награда → повтор». Проверка: весело ли на 0 наградах?
3. **Twist** — в механике (трудно скопировать), не в сеттинге.
4. **Столпы** — 3–5, фальсифицируемые и ограничивающие. Для каждого: что он запрещает. Плюс **North star** — один вопрос-фильтр для любой будущей механики.
5. **Iceberg** — 5 слоёв валидации, отметить WEAK.

Формулировки — слова пользователя, приведённые в форму. Не подставляй свои идеи вместо его.

## Выход

- `design/concept.md` — по шаблону (секции: Искра, Fantasy, Core Loop, Twist, Аудитория, Референсы и анти-референсы, Iceberg, Главный риск).
- `design/pillars.md` — столпы с «запрещает» и примером решения, которое столп отсекает.
- Решения → `design/decisions-log.md`.
- Критерий перехода к `gd-systems-map`: см. роутер, стадия 1.

## Правила
Язык ответа = язык запроса. Художественный текст — только по явной просьбе. Без воды. Если предлагаешь варианты (по просьбе) — маркируй как ГИПОТЕЗА (см. `../gd-router/references/principles.md`).
