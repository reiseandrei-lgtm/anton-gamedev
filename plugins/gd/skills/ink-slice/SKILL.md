# ink-slice

## Вход
Имя слайса. Прочитай: нужную ветку в `design/narrative/branches/`, карточки участвующих персонажей, `voice-pillars.md` (если просят текст), существующий план в `design/narrative/ink/`, существующие `.ink` файлы проекта (спроси путь, если не очевиден).

## Фаза 1 — План
По `references/slice-plan.md`: тип слайса, источники дизайна, какие `.ink` файлы меняются, вход/выход (knots/stitches), переменные read/write, выборы игрока (намерения, не текст), поведение при повторном визите, include/tunnels, критерии приёмки. Один слайс — один план.
Выборы, локализация и телеметрия — по `references/localization-and-telemetry.md`; её критерии приёмки входят в критерии слайса.

## Фаза 2 — Замки и ключи
Каждое препятствие: `id`, тип (knowledge / inventory / skill / relationship / location / world_state), requires, grants, scope, critical_path, fallback_route. Проверки: нет обязательного ключа без источника, нет циклических зависимостей, нет замков, которые ничего не меняют в игре. Новое состояние — только через план, не молча.

## Фаза 3 — Драфт .ink
- Синтаксис: `references/ink-syntax.md` (основное), `ink-syntax-extended.md` (weave, lists, threads — по нужде), стиль: `ink-style-rules.md`.
- **По умолчанию — каркас**: структура knots/stitches, выборы, переменные, diverts, теги; вместо текста — `[РЕПЛИКА: кто, цель, эмоция, что раскрывает]` и `[ВЫБОР: намерение]`.
- Полный текст реплик — только если пользователь явно попросил; тогда опирайся на voice-pillars и карточки.
- Идентификаторы на английском (snake_case), текст — на языке проекта. Правь только файлы из плана.
- Unity-интеграция (ink-unity-integration, теги для FMOD/анимаций) — только как соглашение по тегам в плане, без кода C#.

## Фаза 4 — Проверка
Статически: достижимость от старта до выхода, все выборы возвращаются в нужную петлю, нет случайных односторонних выходов, переменные из Ink есть в плане и наоборот, повторные визиты. Если доступен `inklecate` — можно скомпилировать для проверки, иначе сказать, что проверено статически. Находки: blocking / major / minor.

## Выход
`design/narrative/ink/<slice>.plan.md` (план + замки/ключи + результаты проверки) и `.ink` файлы в репозитории игры (путь подтверждает пользователь).

## Правила
Язык ответа = язык запроса. Художественный текст — только по явной просьбе. Не превращай свободное исследование в линейную последовательность, если план этого не требует.
