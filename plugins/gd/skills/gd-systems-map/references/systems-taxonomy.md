# Systems taxonomy

> Adapted from Claude-Code-Game-Studios `map-systems` and `systems-index` template (MIT © 2026 Donchitos). See ATTRIBUTION.md.

## Категории

| Категория | Что это | Типичные системы |
|---|---|---|
| Core | Фундамент, от него зависит всё | Контроллер игрока, ввод, камера, стейт-машина, сцены |
| Gameplay | То, что делает игру игрой | Бой, ИИ, стелс, взаимодействие, карты/колода |
| Progression | Рост игрока во времени | Уровни, открытия, репутация, дерево навыков |
| Economy | Создание и трата ресурсов | Валюты, лут, крафт, магазины, таблицы дропа |
| Persistence | Сохранение и непрерывность | Сейвы, настройки, профиль, облако |
| UI | Информация для игрока | HUD, меню, инвентарь, журнал, карта |
| Audio | Звук и музыка | Адаптивная музыка, SFX-шины, эмбиент, голос (FMOD) |
| Narrative | Доставка истории | Диалоги, квесты, отношения, катсцены, лор-записи |
| Social / Multiplayer | Взаимодействие игроков | Матчмейкинг, voice, кооп-роли, синхронизация |
| Meta | Вне core loop | Онбординг, аналитика, доступность |

## Приоритеты

| Уровень | Определение | Порядок проработки |
|---|---|---|
| MVP | Без этого нельзя проверить «весело ли» | Первыми |
| Vertical Slice | Нужно для одной законченной отполированной зоны | Вторыми |
| Alpha | Вся механика в грубом виде | Третьими |
| Full Vision | Полировка, edge-кейсы, nice-to-have | По необходимости |

## Слои зависимостей

- **Foundation** — без зависимостей.
- **Core** — зависит от Foundation.
- **Feature** — зависит от Core.
- **Presentation** — обёртки над Feature (UI, VFX, аудио-реакции).

## Проверки

- Каждая система → минимум один столп.
- Нет циклов (A→B→A). Разрыв: общий интерфейс/событие, объединение, инверсия владения.
- MVP-набор замыкает core loop целиком (глагол → фидбек → награда → повтор).
- Системы, появившиеся «для полноты», без связи с loop — флаг.
