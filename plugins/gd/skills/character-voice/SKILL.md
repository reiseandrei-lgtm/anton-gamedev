# character-voice

## Вход
`design/narrative/world.md`, `design/pillars.md`, существующие `characters/`, `voice-pillars.md`, ветки, где персонаж появляется.

## Задачи
- **Voice pillars (проект)** — 3–5 правил голоса всей игры: регистр, ритм, что запрещено (анахронизмы, штампы), юмор, как звучит страх/нежность. Каждое с «делаем / не делаем» в виде описаний, не образцов текста.
- **Персонаж** — карточка по `references/character-models.md`: функция в истории и в геймплее, want / need, рана/противоречие, отношение к центральному конфликту, арка, голосовые маркеры (описания: длина фраз, лексика, что избегает), что знает / скрывает / понимает неверно.
- **Матрица отношений** — пары: текущий статус, напряжение, что может сдвинуть, переменная состояния.
- **Диалоговые темы** — для свободного порядка разговоров: доступность, гейты (знание, предмет, доверие, локация), одноразовые откровения, повторяемые петли, что меняет состояние.

## Процедура
1. Каст держи компактным: две роли, которые можно слить, — предложи слить.
2. Спрашивай решения у автора, варианты — только по просьбе.
3. Голосовые маркеры — описаниями («короткие фразы, уходит от прямых ответов вопросом»), не примерами реплик. Пример реплики — только если пользователь явно попросил.
4. Для каждого говорящего персонажа — эталонный набор и строка в матрице отношений по `references/voice-kit.md`. В режиме текста — правка в три прохода оттуда же.
5. Покажи, потом запиши.

## Выход
`design/narrative/voice-pillars.md`, `design/narrative/characters/<name>.md`, раздел «Relationships» в `characters/_relationships.md`. Новые переменные (trust, отношения) → согласовать с веткой в `branches/`.

## Правила
Язык ответа = язык запроса. **Диалоги, реплики и прозу не писать без явной просьбы.** Без воды.
