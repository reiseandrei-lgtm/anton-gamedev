## 2. Коды наблюдения

| Код | Значение | Когда ставить |
|---|---|---|
| `C` | confusion | пауза > 3 с с поиском, вопрос вслух, неверная попытка |
| `F` | frustration | вздох, ругань, резкие тапы, «да ну» |
| `D` | delight | улыбка, «о!», повтор без причины |
| `S` | stuck | нет прогресса > 30 с |
| `Q` | quit intent | «можно я закончу», откладывает устройство |
| `B` | bug | поведение, которого не может быть по GDD |
| `A` | aha | вслух сформулировал правило или сделал нужное без подсказки |
| `N` | note | нейтральное наблюдение |

Формат строки: `[mm:ss] CODE текст` — например `[01:12] C тапает по счёту, думает, что это кнопка`. Дословная речь — в кавычках.
Файл на игрока `notes/P1.md` или один файл с `## P1`, `## P2`. Первая строка раздела может задать сегмент: `segment: newcomer`.

## 3. Опросник и интервью

После сессии, до объяснений дизайнера:
1. Шкалы 1–5 (3–5 штук, под вопросы): «Насколько понятно было, что делать?», «Насколько хотелось сыграть ещё раз?», «Насколько чувствовал контроль?».
2. Открытые (3): «Расскажи, что происходило в игре своими словами». «Что было самым неприятным моментом?». «Если бы рассказывал другу — что бы сказал?».
3. Проверка понимания: «Как, по-твоему, работает <механика>?» — ответ сверяется с правилом, не оценивается.

Запрещено: «Тебе понравилось X?», «Правда, прыжок приятный?», объяснять задумку до конца интервью, защищать дизайн. Laddering: «что ты имеешь в виду?» → «почему так?» → «чего ожидал?».

## 4. Анализ

**Триангуляция**: находка = 2+ источника из трёх (наблюдение, метрика или скрипт, слова игрока). Один источник — гипотеза для следующего раунда.

**Частота**: системная (≥ 60 % игроков), сегментная (в одном сегменте), индивидуальная (1–2 игрока — не приоритет).

**Тяжесть**:
| P | Значение |
|---|---|
| P0 | ломает гипотезу или игрок уходит / не может продолжить |
| P1 | сильное трение, неверное понимание core-механики |
| P2 | короткая путаница, игрок сам восстанавливается |
| P3 | вкусовое, без влияния на поведение |

**Матрица действия**: P0 × любая частота → до следующего плейтеста · P1 × системная → в следующую итерацию · P1 × сегментная → решение, для какого сегмента игра · P2 → бэклог полировки · P3 → записать, не действовать.

**Ловушки**: подтверждающее искажение (ищешь то, что доказывает гипотезу) · последний тестер весит больше · «я знаю, что он имел в виду» · анализ только тех, кто дошёл до конца.
