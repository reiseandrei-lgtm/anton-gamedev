## 2. Связь с GDD и game feel

| Откуда | Что даёт | Куда в event-map |
|---|---|---|
| Feedback `FBn` с аудио | отдельное событие | Source `<system>#FBn` |
| Game Feel: anticipation | звук подготовки (замах, заряд) | отдельное событие или параметр `charge` |
| Game Feel: impact | главный удар — приоритет 1–2 | событие, часто с вариациями |
| Game Feel: resolution | хвост, подтверждение | стингер или часть события |
| States & Transitions | музыкальное состояние | `music:<state>` + параметр или снапшот |
| Ink-строки с VO | реплика | `ink:<line_id>` |

Правило пустоты: состояние, которое игрок не должен пропустить, без звука и без визуального дубля — находка для ревью.

## 3. Громкость — стартовые якоря (ГИПОТЕЗА)

- Мобайл: игроки часто играют через динамик телефона и без звука. Критичная информация не может передаваться только звуком. Integrated около −16 LUFS — стартовая точка; менять, если на устройстве тихо рядом с другими играми.
- PC / консоль: около −23…−16 LUFS в зависимости от жанра и платформы; true peak ≤ −1 dBTP.
- Проверка — только ушами на целевом устройстве. Скрипт громкость не проверяет.

## 4. Форматы импорта (FMOD for Unity / банки)

| Тип | Load | Кодек (типично) |
|---|---|---|
| Короткие SFX | Decompress / Compressed in memory | Vorbis или ADPCM |
| Музыка, амбиент | Stream | Vorbis |
| VO | Stream | Vorbis |
3D-SFX — моно (панораму даёт спатиализация).

## 5. Бесплатные источники плейсхолдеров

- **Синтез без ключей**: плагин `gd-build`, скилл `slice-build`, скрипт gen_sfx.py (stdlib, ретро-SFX), бесплатные sfxr / jsfxr / ChipTone.
- **Kenney Audio** — CC0.
- **Freesound.org** — лицензия у каждого файла своя: CC0 брать свободно, CC-BY — в титры, CC-BY-NC — не для коммерческой игры.
- **Запись**: Audacity (бесплатно) + телефон — фоли за 10 минут часто лучше стока.
- Платные генераторы (ElevenLabs, генерация Coplay) не использовать.

## 6. Честная проверка

Скилл не слышит. В отчёте всегда: «структура и покрытие проверены скриптом; звучание не проверялось — нужен человек с наушниками и телефоном».
