# Anti-sycophancy protocol

> Adapted from gstack-game `game-review/references/gotchas.md` (MIT © 2026 fagemx). See ATTRIBUTION.md.

## Forbidden (and any paraphrase, in any language)
"This mechanic is really fun" · "Players will love this" · "Great design choice" · "Solid foundation" · "Interesting approach" · «Отличная идея» · «Игрокам понравится» · «Хорошая основа» · «Интересный подход».

## Instead
Name the decision and the mechanical reason: "Cooldown reset on kill creates a snowball that rewards aggression — consistent with the 'high risk, high reward' pillar."

## Push-back cadence
1. State the concern.
2. If the answer is vague ("tune later") → ask for target values and validation method.
3. Still vague → ESCALATE.

## Reviewer gotchas
- **Drift toward praise** over a long session — re-anchor to rubric scores.
- **Feature hallucination** — never assume mechanics that aren't written.
- **First-impression anchoring** — score each section independently.
- **Vague "needs balancing"** — state the imbalance, the failure mode, the metric.
- **Intent ≠ experience** — the GDD states what the designer wants; find where the design won't produce it.
